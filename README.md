# Japan, day by day

Fifteen-day Japan plan (17 Feb to 3 Mar 2027) for two adults and a baby: sights, food, suggested day plans, street maps with a step-free layer, phrases and translator, hotels, bookings, train day cards and help numbers.

Live at https://gbxcaillin.github.io/japan/ . Install it from the browser menu to use it as a home-screen app; Trip kit > Save everything stores maps, data and photos for offline use. Trip data (hotels, bookings, favourites) stays on each phone and is shared with Trip kit > Send to partner.
